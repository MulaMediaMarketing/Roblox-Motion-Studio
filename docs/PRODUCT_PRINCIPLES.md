# Product Principles

## Simple surface, serious engine

The interface should feel approachable:
- clear viewport
- clean top bar
- focused tools
- timeline at the bottom
- contextual properties
- minimal visual clutter

Underneath it should behave like a professional animation package.

## Manual first

A user must be able to create an animation entirely from the timeline and viewport.

No prompt is required.

## Video without prompts

A user can upload a reference video and generate editable animation directly from motion extraction.

## Optional AI

AI assists an animator; it does not replace the animation system.

## Continuous motion

Motion is not fundamentally clip-based. The engine supports continuous curves, interpolation, and smooth blending across the timeline.

## Roblox first, not Roblox forever

Roblox R15 is the first target. The core engine remains generic so additional runtimes can be supported without rewriting the animation editor.
