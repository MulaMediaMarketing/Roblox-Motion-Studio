# Roadmap

## Milestone 0 - Foundation
- repository structure
- coding/security/testing standards
- canonical R15 asset
- schema contract

## Milestone 1 - Animation Core
- skeleton model
- pose model
- keyframes
- interpolation
- smooth blending
- undo/redo command model

## Milestone 2 - Three.js Editor
- R15 viewport
- camera controls
- transform gizmos
- selection
- clean timeline
- dope sheet

## Milestone 3 - Video Motion
- upload pipeline
- pose extraction
- retargeting
- smoothing
- foot locking
- editable generated keys

## Milestone 4 - Roblox Export
- KeyframeSequence exporter
- Studio plugin importer
- round-trip validation

## Milestone 5 - Professional Animation Tools
- graph editor
- motion layers
- pose library
- motion matching
- advanced blending

## Milestone 6 - Optional AI
- natural-language edit commands
- motion cleanup assistants
- pose suggestions

AI remains optional and never becomes a dependency of the basic animation workflow.
